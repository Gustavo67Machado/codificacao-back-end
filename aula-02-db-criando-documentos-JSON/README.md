# Aula 02 — Banco de Dados: Criando Documentos JSON

## 📚 Sobre a aula

Nesta aula foram praticados os fundamentos da criação de documentos no formato **JSON (JavaScript Object Notation)**. Foram criados arquivos com dados estruturados para representar diferentes situações, como cadastro de aluno, produto de loja, publicação em rede social e sistema escolar.

O objetivo foi aprender a organizar informações em pares de chave e valor, utilizando objetos, listas e objetos aninhados.

## 🎯 Objetivos

- Compreender a estrutura básica de um documento JSON;
- Representar informações usando pares de chave e valor;
- Trabalhar com diferentes tipos de dados, como textos, números, datas e listas;
- Criar objetos aninhados;
- Organizar conjuntos de informações relacionadas;
- Praticar a escrita de documentos JSON válidos.

## 🛠️ Tecnologias e ferramentas

- JSON
- Visual Studio Code

## 📁 Arquivos desenvolvidos

Durante a aula, foram criados os seguintes documentos:

### `aluno-escola.json`

Representa o cadastro de um aluno, com informações como:

- Nome e nome social;
- Matrícula;
- Data de nascimento;
- Curso;
- Disciplinas e notas;
- Endereço, incluindo rua, número, bairro, cidade, estado e CEP.

O documento utiliza uma lista de disciplinas e um objeto aninhado para agrupar os dados do endereço.

### `produto-loja-notebook.json`

Representa um produto de uma loja: um notebook. Contém:

- Nome do produto;
- Categoria;
- Preço;
- Quantidade disponível;
- Especificações técnicas, como memória RAM, processador e armazenamento;
- Lista de tags relacionadas ao produto.

Esse arquivo demonstra o uso de números, objetos aninhados e listas de textos.

### `rede-social.json`

Representa uma publicação em uma rede social, com:

- Texto da publicação;
- Autor;
- Informações de curtidas;
- Comentários.

O documento organiza os dados relacionados à publicação em propriedades próprias.

### `sistema-escolar.json`

Representa informações de um estudante em um sistema escolar, incluindo:

- Nome;
- CPF, matrícula e RG;
- Data de nascimento;
- Disciplinas e notas;
- Endereço.

Assim como no cadastro de aluno, utiliza uma lista de disciplinas e um objeto para agrupar os dados de endereço.

## 🧩 Conceitos praticados

- Estrutura de objetos JSON;
- Pares de chave e valor;
- Strings e números;
- Arrays (listas);
- Objetos aninhados;
- Organização de dados por contexto;
- Formatação e legibilidade de documentos JSON.

## ✅ Resultado

Ao final da atividade, foram criados quatro arquivos JSON com estruturas diferentes para representar dados de alunos, produtos, publicações em redes sociais e registros escolares.
